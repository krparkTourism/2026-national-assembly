# 한국문화관광연구원 · 2026년 국정감사 대시보드

한국문화관광연구원(KCTI)의 **2026년 국정감사 대비 기관 현황·주요 현안**을 한 화면에서 확인할 수 있는 반응형 대시보드입니다.

## 특징

- **완전 반응형** — PC / 태블릿 / 스마트폰(iOS · Android) 모두 최적화
- **단일 파일** — `index.html` 하나로 동작. 별도 서버·빌드 불필요
- **CDN 라이브러리만 사용** — Chart.js + Google Fonts (Noto Sans KR)
- **직관적 정보 구조** — 8개 탭 (개요 / 조직·정원 / 예산 / 연구·사업 / 통계·평가 / 주요 현안 / 2026 과제 / 타 기관 비교)
- **인터랙티브 차트 8종** — 예산 추이, 지원율 추이, 수입·지출 구성, 임금피크제, 기관 비교 등
- **2026 기본연구과제 39건 검색·필터** — 분야(문화·관광·콘텐츠·데이터) 및 유형(기초·정책·수시)별 필터, 키워드 검색

## GitHub Pages 배포 방법

1. 새 GitHub 저장소 생성 (예: `kcti-2026-audit`)
2. `index.html` 파일을 저장소 루트에 업로드
3. **Settings → Pages** 로 이동
4. Source 를 **Deploy from a branch** → `main` 브랜치 · `/ (root)` 폴더 선택 → Save
5. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능
